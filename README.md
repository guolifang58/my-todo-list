# 📝 我的待办清单

一个简洁实用的网页版待办清单（Todo List），纯原生技术实现，无需任何运行环境。

![界面截图](docs/screenshot.png)

## ✨ 功能特性

- ➕ **快速添加**：输入内容后点按钮或按 `回车` 即可添加
- ✅ **标记完成**：勾选复选框，文字自动划线变灰
- 🗑️ **单条删除**：每条右侧 ✕ 按钮可单独删除
- 🧹 **批量清除**：一键清除所有已完成项
- 📊 **实时统计**：底部显示「共 N 项，已完成 M 项」
- 💬 **空状态提示**：无任务时给出友好引导

## ️ 技术栈

- **HTML5** —— 页面结构
- **CSS3** —— Flex 布局、渐变背景、悬停动效
- **原生 JavaScript** —— 数据渲染与交互，零依赖

## 🧠 核心实现思路

数据与视图分离的经典模式：

- 用一个数组 `todos` 存所有任务，每项形如 `{ text, done }`
- 所有增删改操作只修改 `todos` 数组
- 每次改完调用 `render()`，清空列表 DOM 并根据数组重新渲染

这就是现代前端框架（React / Vue）「数据驱动视图」的最朴素版本。
